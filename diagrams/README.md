# Diagrammi della tesi

Questa cartella raccoglie i diagrammi utilizzati nella tesi di FleetManager.

## Contenuto

- `use-case/fleetmanager-use-case.puml`: sorgente PlantUML modificabile.
- `use-case/fleetmanager-use-case.svg`: versione vettoriale pronta per essere inserita nel documento.

Per rigenerare l'SVG con PlantUML:

```sh
plantuml -tsvg diagrams/use-case/fleetmanager-use-case.puml
```
